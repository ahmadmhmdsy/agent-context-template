# general — memory shard

Lessons that do not belong to a narrower topic.

## 2026-01-01 — Write lessons as they are learned

- **Status:** observed
- **Lesson:** Record a lesson the moment it is learned, not at the end of the
  session. Session-end memory writes are the ones that get skipped when the
  session ends abruptly, and they are always the most valuable ones.
- **Evidence:** `rules/17-learning-loop.md` (R-17.2 — *observed* means written
  into a memory shard immediately).

## 2026-01-01 — A lesson needs its condition

- **Status:** observed
- **Lesson:** A lesson without its condition becomes a superstition. "Never do
  X" is usually "never do X while Y holds"; write the Y.
- **Evidence:** `_templates/lesson.md` (fill rule: *State the condition. An
  unconditional lesson becomes wrong the moment the environment changes.*)
